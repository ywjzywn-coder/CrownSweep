## 0.3.1 — 2026-10-02

- 独立公开品牌改为 CrownSweep，保留原有 bundle identifier 及内部 package/crate 名称，减少升级身份变化。
- 将 GUI 源码组织在上游 fork 的 `gui/`，保留原始 CLI、版权、GPL、商标说明和提交历史。
- 补充第三方归属、依赖版本及许可证全文；设置页可查看开源声明。
- 按目标架构编译 SMC helper；完善 Developer ID 内外层签名、公证、staple 和 Gatekeeper 验证脚本。
- 添加 GUI 独立 CI，重写公开 README、维护交接和发布手册，排除本地缓存、生成二进制和凭据文件。
- 声明目标为 macOS 12.0+；此版本为公开源码版本。真实证书签名、公证、Intel 运行及最低系统兼容性仍需实际验证。未将真实清理、卸载或优化作为回归测试。

## 0.3.0 — 2026-10-02

- 移除可交互终端与 xterm 依赖，所有现有任务改为 GUI 状态、确认、授权、动态和结果。
- 卸载支持应用匹配与关联文件两次明确确认，取消不再误报成功；移除 CLI 完整向导入口。
- 清理增加完整范围确认、系统缓存授权/跳过按钮、全部项目展开与运行时保护名单锁定。
- 密码使用独立安全输入接口，发送前检查 PTY 关闭回显；不保存密码。
- 优化范围对齐当前引擎，增加执行前确认；设置支持直接开关 Touch ID 和选择更新频道。
- 修复安装脚本退出码被覆盖、空应用数组错误回退、清理大小把项目数量计入数值的问题。
- 保留跨页后台任务及执行结果，新增模拟 GUI 流程回归测试。
